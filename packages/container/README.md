# @talosjs/container

Dependency-free injection container — manages service lifecycle with singleton, transient, and request-scoped registrations and resolves constructor dependencies declared with `@inject`

## Installation

```bash
bun add @talosjs/container
```

## Documentation

Read the full documentation at [docs.talosjs.com/advanced/dependency-injection](https://docs.talosjs.com/advanced/dependency-injection).
