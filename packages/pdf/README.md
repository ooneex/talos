# @talosjs/pdf

PDF content extraction toolkit built on `@firecrawl/pdf-inspector` — classifies a PDF (text-based, scanned, image-based, or mixed) and converts it to Markdown

## Installation

```bash
bun add @talosjs/pdf
```

## Documentation

Read the full documentation at [docs.talosjs.com/utilities/pdf](https://docs.talosjs.com/utilities/pdf).
