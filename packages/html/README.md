# @talosjs/html

Dependency-free HTML parsing and DOM manipulation toolkit — an HTML5 parser, CSS selector engine, and jQuery-like API to extract, transform, and query HTML content

## Installation

```bash
bun add @talosjs/html
```

## Documentation

Read the full documentation at [docs.talosjs.com/utilities/html](https://docs.talosjs.com/utilities/html).
